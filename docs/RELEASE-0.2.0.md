# Agenda Clara 0.2.0 — equipe e horários

O responsável agora cadastra e edita profissionais, ativa ou inativa cadastros e configura o expediente semanal pelo painel **Equipe e horários**.

- Até quatro intervalos por dia, com passos de 15 minutos, dias fechados e cópia dos dias úteis.
- Proteção dos atendimentos confirmados: mudanças incompatíveis são recusadas sem alterações parciais.
- Proteção contra edição desatualizada e concorrência com reservas.
- Mesmo recurso no site, no celular e na PWA instalada.
- Migração aditiva do banco, testes ampliados e documentação de uso.

**Site:** https://agenda-clara-luizcodebr.onrender.com

**Teste local:** baixe AgendaClara-0.2.0-demo.zip, extraia em uma pasta gravável e execute iniciar-demo.cmd (Windows) ou bash iniciar-demo.sh (Linux/macOS). Requer Java 21 a 27. O arquivo executável agora se chama agenda-clara.jar.

**Código-fonte:** AgendaClara-0.2.0-fonte.zip. Para desenvolver, instale JDK 21+ compatível e Node 24.18+ da linha 24 ou 26+.

As contas de exemplo estão no README e na tela de acesso. A hospedagem é uma demonstração pública com dados fictícios e descartáveis. A versão local guarda os dados em sua pasta data. O cadastro de profissionais não cria contas de login.
