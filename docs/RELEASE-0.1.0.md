Primeira versão funcional de demonstração do Agenda Clara.

- Site responsivo e instalação como aplicativo pelo navegador (PWA).
- Reservas por serviço, profissional, expediente e duração.
- Painel por estabelecimento, remarcação, cancelamento e bloqueios.
- Proteção contra sobreposição e repetição de confirmação.
- Demonstração local com banco próprio, independente da hospedagem.

**Site:** https://agenda-clara-luizcodebr.onrender.com

Para experimentar localmente, baixe **AgendaClara-0.1.0-demo.zip**, extraia e execute iniciar-demo.cmd (Windows) ou bash iniciar-demo.sh (Linux/macOS). Requer somente Java 21 a 27.

O pacote **AgendaClara-0.1.0-fonte.zip** contém o projeto Java/React e a documentação. Para desenvolver: JDK 21+ e Node 24.18+ da linha 24.

Esta é uma demonstração com dados fictícios e contas compartilhadas. A hospedagem gratuita pode reiniciar os dados de teste. Gestão de profissionais/expedientes, cadastro de empresas e configuração para clientes reais são etapas futuras.

O arquivo SHA256SUMS.txt permite conferir a integridade dos downloads.
